# Microevolution Lab
In this lab, we will be using R to learn about Hardy-Weinberg equilibrium and the forces of evolution. This lab should take two weeks. 

## Learning Objectives
- Learn about Hardy-Weinberg equilibrium as the null hypothesis for evolution
- Learn about how the forces of evolution interact with one another
- Learn how to use R and RStudio for statistics and data visualization

## Pre-Lab
1. Download [R](https://www.r-project.org) and install
2. Download [RStudio](https://docs.posit.co/ide/user/download.html) and install
3. Work through the R Tutorials in [Chapter 1](https://michitobler.github.io/primer-of-evolution/what-evolution-is.html)
4. Work through the R Tutorials in [Chapter 2](https://michitobler.github.io/primer-of-evolution/evidence-for-evolution.html)
5. Work through the R Tutorials in [Chapter 3](https://michitobler.github.io/primer-of-evolution/a-mechanism-for-change.html)

## Lab Procedures
These labs will be performed in RStudio.

### Hardy-Weinberg Equilibrium
1. Read [Chapter 4](https://michitobler.github.io/primer-of-evolution/the-raw-materials-for-evolution.html#case-study-hardy-weinberg-equilirbium)
2. Download the [Chapter 4 case study](https://michitobler.github.io/primer-of-evolution/exercises/BIOL520-ex3.zip)
3. Open the R markdown file in RStudio
4. Work through the case study
5. Which population of flies are in HWE? 

### Forces of Evolution
1. Read [Chapter 5](https://michitobler.github.io/primer-of-evolution/evolutionary-mechanisms-i-modeling-selection.html)
2. Work through the R tutorials in the chapter
3. Download the [Chapter 5 case study: modeling selection](https://michitobler.github.io/primer-of-evolution/exercises/BIOL520-ex4.zip)
4. Open the R markdown file in RStudio
5. Answer the questions
6. Read [Chapter 6](https://michitobler.github.io/primer-of-evolution/evolutionary-mechanisms-ii-mutation-genetic-drift-migration-and-non-random-mating.html)
7.Work through the R tutorials in the chapter
8. Download the [Chapter 6 case study: Mutation and Genetic Drift](https://michitobler.github.io/primer-of-evolution/exercises/BIOL520-ex5.zip)
9. Open the R markdown file in RStudio
10. Answer the questions

## Assessment
1. Show me the work for Hardy-Weinberg Equilibrium for 10 points.
2. Show me the work for Forces of Evolution for 10 points.
