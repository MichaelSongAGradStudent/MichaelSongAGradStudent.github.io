# Animal Diversity Lab
In this lab, we will be learning about animal diversity and how to infer a phylogeny from molecular characters. 

## Learning Objectives
- Learn the major groups of Animalia
- Learn how to use Genbank to download sequence data in the fasta format
- Learn how to make a sequence alignment.
- Learn how to infer a phylogeny from molecular data using maximum likelihood. 

## Pre-Lab
1. Read about the [animal phyla](https://simple.wikipedia.org/wiki/List_of_animal_phyla)
2. Read about [DNA barcoding](https://en.wikipedia.org/wiki/DNA_barcoding)
3. Watch how to [download genes from NCBI GenBank the in fasta format](https://www.youtube.com/watch?v=lAYGUo08eRY)

## Lab Procedures
- Look and draw the following organisms, note the killer synapomorphies for each taxon.
    1. Porifera
    2. Cnidaria
    3. Echinodermata
    4. Chordata
    5. Platyhelminthes
    6. Syndermata
    7. Mollusca
    8. Annelida
    9. Nemotoda
    10. Arthropoda
     - Arachnida
     - Crustacea
     - Myriapoda
     - Xiphosura
     - Coleoptera
     - Diptera
     - Hymenoptera
     - Lepidoptera
     - Othoptera
     - Hemiptera
     - Mantodea
     - Blattodea
     - Odonata
- Make Make a dichotomous key to identify these 23 taxa.
- Using NCBI GenBank, download the COI gene for a species from each of the ten phyla listed above. Paste each fasta sequence in one text file. Remember to keep the headers.
- Upload or paste the sequences into [this online alignment and tree inference portal](https://www.phylogeny.fr/analysis/one-click)
- Look at your alignment and phylogeny!
